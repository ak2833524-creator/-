# 노인맞춤돌봄서비스 생활지원사 12인 통합 관리대장

2026년도 노인맞춤돌봄서비스 실무 표준 지침을 준수한 생활지원사 12인 통합 관리 시스템입니다.

## 📌 주요 기능
1. **12인 생활지원사 현황 관리** : 권역별 배정, 연락처, 근무상태, 상호 대체인력 매칭
2. **담당 어르신 명단 관리** : 중점돌봄(주 2~3회) / 일반돌봄(주 1회+유선) 구분 및 비상연락망
3. **어르신 특이사항 보고 및 조치대장** : 병원동행, 낙상/응급, 영양상태 등 긴급도별 실시간 관리
4. **휴가 및 대체인력 관리대장** : 연차/반차/병가 신청, 업무대행자 지정, 안전확인 공백 방지
5. **수파베이스(Supabase) 클라우드 DB 연동** : PostgreSQL 기반 실시간 동기화, RLS 보안 적용, 오프라인 로컬 폴백
6. **엑셀(.xlsx) 내보내기 및 결재용 인쇄 지원** : [담당 - 전담사회복지사 - 센터장] 결재란 포함

## 📂 파일 구성
- `index.html` : 한눈에 보는 통합 관리대장 웹 애플리케이션 (Supabase 클라이언트 내장)
- `schema.sql` : Supabase 데이터베이스 테이블, RLS 정책, 초기 12인 시드 데이터 생성 쿼리
- `노인맞춤돌봄_생활지원사12인_통합관리대장.xlsx` : Microsoft Excel 연동 관리대장

## ⚡ Supabase 데이터베이스 연동 방법

### 1단계: Supabase 프로젝트 생성
1. [Supabase 공식 사이트](https://supabase.com/)에 로그인하고 새 프로젝트(New project)를 만듭니다.

### 2단계: 데이터베이스 테이블 생성 (SQL Editor)
1. Supabase 대시보드 좌측 메뉴에서 **SQL Editor**로 이동합니다.
2. 프로젝트 내 `schema.sql` 파일의 내용을 전체 복사하여 SQL Editor에 붙여넣습니다.
3. **Run** 버튼을 클릭하여 실행합니다.
   - `care_workers` (생활지원사 12인)
   - `care_seniors` (어르신 명단)
   - `care_reports` (특이사항 보고대장)
   - `care_leaves` (휴가 및 대체인력 대장)
   - 보안을 위한 RLS 정책 및 Realtime 채널 활성화가 자동으로 설정됩니다.

### 3단계: 웹앱에서 API 키 연결
1. Supabase 대시보드 **Project Settings** > **API** 메뉴로 이동합니다.
2. **Project URL**과 **anon public API Key**를 확인합니다.
3. 웹앱([index.html](index.html)) 상단의 **[⚡ Supabase 연동 설정]** 버튼을 클릭합니다.
4. Project URL과 Anon Key를 입력하고 **[연결 테스트 및 저장]**을 누르면 즉시 실시간 클라우드 DB 연동이 시작됩니다!
