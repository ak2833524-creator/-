# 노인맞춤돌봄서비스 생활지원사 12인 통합 관리대장

2026년도 노인맞춤돌봄서비스 실무 표준 지침을 준수한 생활지원사 12인 통합 관리 시스템입니다.

## 📌 주요 기능
1. **12인 생활지원사 현황 관리** : 권역별 배정, 연락처, 근무상태, 상호 대체인력 매칭
2. **담당 어르신 명단 관리** : 중점돌봄(주 2~3회) / 일반돌봄(주 1회+유선) 구분 및 비상연락망
3. **어르신 특이사항 보고 및 조치대장** : 병원동행, 낙상/응급, 영양상태 등 긴급도별 실시간 관리
4. **휴가 및 대체인력 관리대장** : 연차/반차/병가 신청, 업무대행자 지정, 안전확인 공백 방지
5. **엑셀(.xls / CSV) 내보내기 및 결재용 인쇄 지원** : [담당 - 전담사회복지사 - 센터장] 결재란 포함

## 📂 파일 구성
- `index.html` : 한눈에 보는 통합 관리대장 웹 애플리케이션
- `노인맞춤돌봄_생활지원사12명_통합관리대장.xls` : Microsoft Excel 연동 4개 시트 통합 관리대장
